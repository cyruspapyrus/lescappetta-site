# lescappetta.com

One-page site for Les Cappetta and Strategic Leadership Advisors, LLC. Static HTML on GitHub Pages
(custom domain in `CNAME`, DNS at Namecheap). No build step: push to `main` and Pages publishes it.

- `index.html` holds the page and its styles. `img/les-cappetta.jpg` is the headshot from his ACI-NA
  leadership page, a stand-in until Les sends his own.
- Stock photos are Unsplash (free license) loaded from `images.unsplash.com`: 1542296332 (hero),
  1627750673161, 1740064038442, 1573076978602, 1715268358642 (cards).
- The page carries `noindex` while Les reviews it. Delete that `<meta name="robots">` line to launch.
